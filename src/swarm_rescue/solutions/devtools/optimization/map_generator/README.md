# 复赛地图生成器

根目录运行 `.\generate_maps.cmd 1`，只改数量即可。默认semifinal/hard，1700×1100或1660×1122，支持无通信区和无定位区。自动续编号，JSON/PNG保存在map_data，Python仅在solutions内。正式评测需先完成R0工具适配。
